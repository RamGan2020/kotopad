# Котопад

Небольшая браузерная 3D-игра: игрок управляет котом и за 60 секунд должен нанести квартире как можно больший ущерб. Предметы можно толкать и разрушать, а серии разрушений увеличивают множитель очков.

Проект использует **Three.js** для 3D-графики, **Vite** для запуска локального сервера и сборки, а также стандартный **Web Audio API** для звуков.

## Необходимое ПО

Перед установкой проекта понадобятся:

1. **Node.js 22.12 или новее** — среда запуска JavaScript вне браузера. Рекомендуется актуальная LTS-версия с сайта [nodejs.org](https://nodejs.org/).
2. **npm** — менеджер пакетов. Он устанавливается вместе с Node.js, отдельно устанавливать его не нужно.
3. **Современный браузер** — Chrome, Edge, Firefox или Safari с поддержкой WebGL.
4. **Git** — нужен только для скачивания проекта командой `git clone` и работы с репозиторием: [git-scm.com](https://git-scm.com/downloads).

Visual Studio Code или другой редактор кода необязателен, но удобен для изучения и изменения проекта.

## Установка

### Вариант 1. Скачать через Git

Откройте терминал в папке, где должен появиться проект, и выполните:

```bash
git clone https://github.com/YOUR_USERNAME/kotopad.git
cd kotopad
npm install
```

Замените `YOUR_USERNAME` на имя владельца репозитория.

### Вариант 2. Скачать ZIP-архив

1. Откройте страницу репозитория на GitHub.
2. Нажмите **Code → Download ZIP**.
3. Распакуйте архив.
4. Откройте терминал в распакованной папке.
5. Выполните `npm install`.

Команда `npm install` один раз скачивает зависимости, указанные в `package.json`, и создаёт папку `node_modules`.

## Запуск игры

В папке проекта выполните:

```bash
npm run dev
```

В терминале появится адрес локального сервера, обычно:

```text
http://localhost:5173
```

Откройте этот адрес в браузере и нажмите **«Устроить котопад»**. Сервер должен оставаться запущенным во время игры. Для его остановки нажмите `Ctrl+C` в терминале.

## Управление

| Действие | Управление |
|---|---|
| Движение | `WASD` или стрелки |
| Рывок | `Shift` |
| Прыжок | `Space` |
| Удар лапой | `F` или короткий клик левой кнопкой мыши |
| Вращение камеры | Перетаскивание мышью по сцене |
| Масштаб камеры | Колёсико мыши |
| Пауза | `Esc` или `P` |
| Начать новый раунд | Кнопка на экране результата или `Enter` |

Тяжёлая мебель получает больше урона при столкновении во время рывка. Разрушайте предметы один за другим с интервалом менее 3,2 секунды, чтобы сохранить комбо.

## Проверка и производственная сборка

Создать готовую версию для размещения на хостинге:

```bash
npm run build
```

Результат появится в папке `dist`.

Проверить собранную версию локально:

```bash
npm run preview
```

После команды терминал покажет адрес предпросмотра.

## Структура проекта

```text
index.html          HTML-разметка и экраны интерфейса
src/main.js         Главный игровой цикл, состояния, счёт и управление
src/cat.js          Модель, движение и анимация кота
src/apartment.js    Построение квартиры и предметов
src/items.js        Физика, столкновения, разрушения и осколки
src/audio.js        Генерация звуков
src/style.css       Оформление интерфейса
package.json        Зависимости и команды npm
```

Комментарии внутри исходных файлов объясняют работу основных алгоритмов.

## Если что-то не работает

- **«npm не является внутренней или внешней командой»** — Node.js не установлен или терминал открыт до установки. Установите Node.js и перезапустите терминал.
- **Порт 5173 занят** — Vite автоматически выберет другой порт. Откройте адрес, который фактически напечатан в терминале.
- **Чёрный экран или ошибка WebGL** — обновите браузер и включите аппаратное ускорение в его настройках.
- **Не открывается адрес после остановки сервера** — снова выполните `npm run dev` в папке проекта.
